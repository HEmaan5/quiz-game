# quiz-game
Interactive multiple-choice web development quiz built with HTML, CSS and vanilla JavaScript. Uses the DOM to update questions, track the score and show a final result screen.

A multiple-choice quiz built with HTML5, CSS3 and vanilla JavaScript.

## Features
- 8 web development questions
- DOM updates for each question and its options
- Live score tracking and progress bar
- Instant correct/wrong feedback
- Final result screen with a score message and a Play Again button
- Responsive design

## Technologies
HTML5, CSS3, JavaScript (ES6)

## How to run
1. Download or clone the repository.
2. Open `index.html` in your browser.
